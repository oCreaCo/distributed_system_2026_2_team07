# [2026-11-14 21:32] LLM 모델 pilot: DeepSeek v4.1 flash vs Gemini 3.8 flash

## 목표
$50 예산 안에서 쓸 flash급 모델을 정한다. 같은 탐색(adaevolve), 같은 iteration(15), 같은 seed 프로그램과 프롬프트.

## 수행
- OpenRouter 가격(1M 토큰당 입력/출력): deepseek-v4.1-flash $0.051/$0.203, gemini-3.8-flash $0.825/$4.125, glm-5.3-flashx $0.37/$1.25.
- 실행 스크립트: 모델마다 `config.yaml`의 모델 이름만 바꾼 사본으로
  `skydiscover optimize ... -s adaevolve -i 15 -o adrs/dtfm_placement/output/pilot_<model>` 실행, 전후 `GET /api/v1/key`의 usage로 비용 기록.
- 최고 프로그램을 held-out topology(seed 100–102)로 재채점:
  `skydiscover/.venv/bin/python adrs/dtfm_placement/evaluator.py <best_program.py> heldout`

- 기준: seed 1.048, ga_sim(DT-FM GCMA + 시뮬레이터) train 1.217 / held-out 1.256.
- DeepSeek: iteration당 약 $0.027, LLM 응답 10–100 s. Gemini: iteration당 약 $0.088, LLM 응답 1–2.5분.
- 두 모델 모두 15 iteration 만에 ga_sim을 train에서 약 2.7% 넘었다. held-out에서는 DeepSeek +1.7%, Gemini −0.1%.

DeepSeek 최고 프로그램(368줄)의 구조:
1. 실효 대역폭 모델 `min(bw, 40/delay)`로 대칭 링크 비용 행렬을 만들고, `w·dp_sum + pipe_sum + γ·pipe_max` proxy로 simulated annealing 재시작(가중치를 바꿔 가며).
2. 다양한 후보를 실제 `cost_fn`으로 평가해 proxy 항들에 ridge 회귀를 적합.
3. 보정된 proxy로 swap 후보를 골라 실제 비용으로 개선 확인하는 국소 탐색, 정체 시 perturbation. PP=1이면 medoid hub로 구성.

## 판단
- **주력 모델: deepseek-v4.1-flash.** 점수는 같고 3.3배 싸고 2.3배 빠르다.
- 주의: 모델당 1회 실행이라 품질 차이는 판단할 수 없다. ga_sim 대비 1–3% 차이는 ga_sim의 seed 하나에서 나온 값이라,
  ga_sim을 여러 seed로 돌려 분산을 확인하기 전에는 "DT-FM 탐색보다 낫다"고 단정하면 안 된다.
- DeepSeek 프로그램은 시뮬레이터 호출 외에 proxy 계산에 wall-clock을 많이 쓴다(8.5 s, 제한 30 s). 비교 시 호출 수와 함께 시간도 보고할 것.
