## CEGAS 요약 (논문 `paper/sections/method/*.tex`)
- 진화 대신 에이전트 하나가 도구로 draft를 고친다: 과거 프로그램 열람·전환, 입력 하나로 실행, 비교, 메모, 블록 편집/전체 재작성.
  편집에 `evaluate=true`를 붙이면 같은 호출에서 공식 평가까지 한다.
- 작은 test suite(입력 8개, 입력별 품질 함수)로 평가할 때마다 draft를 검사한다. 입력 i의 목표는
  `(1−tol)·max(parent_i, reference_i)`이고(최소화 과제는 `(1+tol)·min(...)`), 못 미친 입력은 반례로 점수와 함께 돌려준다.
  평가는 막지 않는다(advice; `gate_release_after_requests: 0`).
- reference = 기존 optimizer가 같은 과제에서 찾은 최고 프로그램. 에이전트는 코드를 못 보고 입력별 점수만 본다.
- 비용 = LLM 호출 수. 논문 ADRS 설정은 100회.

## 우리 과제에 맞춘 구현 (`adrs/dtfm_placement/cegas/`)
TCResearch 코드는 수정하지 않고 `PYTHONPATH=~/TCResearch/tcopt`로 사용한다 (우리 venv와 vendored SkyDiscover에서 import 확인).
